# MR NEON — سورس اصلی پروژه

MR NEON یک وب‌اپلیکیشن PHP با رابط فارسی/RTL است. نسخهٔ موجود شامل وب‌سایت عمومی، جریان‌های احراز هویت و ثبت‌نام، ساخت و پیگیری درخواست پروژه، فضای کاربر و پنل مدیریت است. این مخزن فقط یک وب‌سایت استاتیک HTML نیست؛ API و عملیات اصلی سمت سرور به PHP و پایگاه داده وابسته‌اند. ZIP تحویلی یک source snapshot است و پوشهٔ `.git`/تاریخچهٔ کامل commitها را درون خود ندارد؛ برای کار Git باید مخزن را clone کنید و روی branch/commit ثبت‌شده قرار بگیرید.

## اجرای محلی

1. پروژه را در یک کپی جداگانه داخل Document Root محیط محلی Apache/XAMPP قرار دهید.
2. PHP سازگار با کد و MariaDB/MySQL با `pdo_mysql` را فعال کنید. هدف مستندشده در `docs/DATA-MODEL.md`، MariaDB 10.6+ یا MySQL 8.0.16+ است؛ نسخهٔ واقعی XAMPP مالک هنوز ثبت نشده و باید بررسی شود.
3. تنظیمات را در محیط Apache/PHP یا محیط خصوصی میزبان قرار دهید. `config.php` از `getenv()` می‌خواند. فایل `.env.example` فقط نمونهٔ نام تنظیم‌هاست و خود PHP آن را بارگذاری نمی‌کند.
4. پیش از هر اتصال یا Migration، نام میزبان و دیتابیس هدف را کنترل کنید. `php bin/migrate.php status` برای مشاهدهٔ وضعیت است؛ `apply` ساختار دیتابیس را تغییر می‌دهد و نباید روی دیتابیس ناشناخته اجرا شود.
5. نقطهٔ ورود رابط `index.php` و نقطهٔ API هم‌مبدأ `api.php` است. صفحه‌ها و قطعه‌های HTML از CSS و JavaScript موجود در `css/`, `js/` و `components/` استفاده می‌کنند.

جزئیات دقیق، متغیرهای محیطی، خطرها و روال‌های عملیاتی در پوشهٔ `docs/` هستند. برای ادامهٔ کار AI در چت جدید، فایل `handoff/00-START-HERE-CHATGPT.md` و سپس `handoff/STATE.md` و `handoff/workflow/AI-OPS.md` را بخوانید.

## پشتهٔ فنی

- Backend: PHP، PDO، کنترلرها و سرویس‌های داخلی.
- Database: MariaDB/MySQL؛ ۱۸ فایل migration و ۱۷ جدول در `SchemaCatalog`.
- Frontend: HTML، CSS، JavaScript ES modules و قطعه‌های HTML.
- Assets: فونت محلی Vazirmatn با مجوز همراه؛ بدون نیاز به دانلود جداگانهٔ آن.
- Tests/CI: PHP unit، JavaScript client tests، Python static contracts و تست‌های integration مبتنی بر MariaDB.

## نکات امنیتی

- هرگز `.env` واقعی، رمز، توکن، فایل پشتیبان، dump دیتابیس، یا اطلاعات مشتری را commit یا در ZIP قابل‌ارسال قرار ندهید.
- از `.htaccess` برای حفاظت Apache استفاده شده است؛ Nginx و میزبان‌های دیگر به قواعد معادل در تنظیمات خود نیاز دارند.
- `data/` و `MRNEON_BACKUP_DIR` را بدون بررسی مسیر واقعی Document Root و مجوزهای فایل جابه‌جا یا منتشر نکنید.
- فهرست API و محدودیت‌های قرارداد در `docs/API-CONTRACT.md` است؛ تغییر قرارداد، احراز هویت، migration یا داده نیازمند بازبینی و مجوز مشخص است.
