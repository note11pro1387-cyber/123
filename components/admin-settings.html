زیرساخت محدودیت نرخ پیش از اجرای همین API فعال است؛ اگر این زیرساخت درخواست را رد کند، خلاصهٔ تنظیمات قابل دریافت نیست و سلامت سایر مقادیر از این خطا نتیجه‌گیری نمی‌شود.

محدودهٔ این گزارش: فقط حضور و اعتبارسنجی محدود تنظیمات در زمان درخواست. این گزارش جایگزین بررسی Host، HTTPS، مجوزهای فایل، آزمون واقعی ارسال/دریافت، بازبینی امنیتی، بررسی Recovery Codes یا تأیید Release Gate نیست. این صفحه تنظیمات را ویرایش یا ذخیره نمی‌کند.
